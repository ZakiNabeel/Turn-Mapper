# ML improvement plan (from 2026-10-19)

Goal: make the learned segmenter worth using, measured honestly. That means at least matching classical on the 12 synthetic cases and beating it on real floors where classical breaks, with the evidence recorded. Baseline: S2 (`docs/RESULTS_ML_S2_2026-10-17.md`) reaches 0.78 test mIoU on ResPlan, but in the pipeline it matches classical on only 8/12 synthetic cases. Its failures are extra rooms, double-line drawings and some missed routes.

## Why S2 underperforms (findings, 2026-10-19)

1. **The pipeline throws away most of what the network predicts.** `learned/segmenter.py` keeps only `wall`, `floor` and `background`:
   - The network's **door** class becomes plain floor, and doors are then re-guessed by wall-gap closing that was tuned for classical masks.
   - **room / walkable** (corridor) is discarded, and the corridor is re-guessed from the largest space plus door count.
   - Class **probabilities** are reduced to argmax, so a thin wall with 45% confidence disappears and splits a room.
2. **The input scale comes from the classical segmenter.** The plan is resized so its walls match the training wall thickness (`wall_px_median`, 9.6 px), and the wall thickness is measured on the *classical* mask. On drawings where classical is wrong (double-line) the network sees the plan at the wrong size. The L-shape double-line case had a −51% scale error with S2.
3. **Double-line in the test set is drawn differently from training.** The test style uses 1 px lines with a gap of wall width + 4 px. The training renderer draws 1–2 px lines inside the wall outline.
4. **Weak labels.** ResPlan "walkable" means leftover circulation (test IoU 0.12). Lifts are rare (0.09).
5. **A saturated test.** The 12 synthetic cases were generated by the code the classical rules were tuned on, so classical scores 1.0. There is no real-floor test yet, which is where learning should win.

## Rules (unchanged, ADR-009)

- The 12 synthetic cases and the FAST A block are **test** sets. Nothing is tuned on them.
- Tuning uses a separate **dev set**: freshly generated institutional floors (seed 2026, never used for training) in all 8 styles, plus the double-line variants, with exact masks, room and door ground truth.
- Every number goes in `docs/RESULTS_*.md` with the notebook name, version and commit.

## Phases

| # | Phase | Work | Where | Done when |
|---|---|---|---|---|
| A | Diagnose | `scripts/diagnose_learned.py`: per case, saves image, classical mask, S2 argmax, S2 wall probability, and the pipeline overlays for both; reports wall breaks, false wall fragments and the chosen scale | Kaggle (CPU) | images viewed and the failure modes confirmed |
| B | Use the whole prediction | `LearnedSegmenter` v2, each option a parameter:<br>(1) **test-time scale search**: try several scales, keep the most confident<br>(2) wall = p(wall) > τ, plus **wall clean-up** (close short breaks, drop small isolated fragments)<br>(3) **network doors**: door-class blobs become known openings in `vectorize` (`Segmentation.doors`)<br>(4) **corridor hint** from the walkable class | code here, unit tests with synthetic probability maps | tests pass; classical behaviour unchanged |
| C | Tune on dev, then test once | `eval/evaluate_dev.py` (room/door recall and precision, routes, wall crossings against generator ground truth); grid over B's options on the dev set; best config run **once** on the 12 synthetic cases | Kaggle (CPU) | table recorded |
| D | Hybrid | `--segmenter hybrid`: classical walls ∪ confident learned walls, network doors, and a per-floor choice by validation score (graph parts, routes, wall crossings) | code + Kaggle | compared with classical and learned v2 |
| E | Retrain S3a | renderer fixes:<br>- double-line variety (1–2 px lines, gap 0–6 px wider than the wall)<br>- residual-circulation label for ResPlan<br>- lift oversampling<br>`--amp --max-minutes 300`, init S2 | Kaggle (GPU) | eval table, S2 vs S3a |
| F | Real test set | Zaki annotates 3–4 FAST **A**-block floors in Studio (frozen); `eval/evaluate_real.py` compares any segmenter's map to them | Studio + here | first real-floor numbers |
| G | S3 (real data) | corrected FAST **B/C** floors from Studio plus S3a replay | Kaggle (GPU) | eval on dev, synthetic and the A block |

The promotion rule stays: learned or hybrid becomes the default only if it is at least as good as classical on 10/12 synthetic cases **and** on the A block.
